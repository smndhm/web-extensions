**Deezer Link est remplacé par [Music Bridge](https://addons.mozilla.org/firefox/addon/music-bridge/)**, du même développeur : choisissez Deezer et cochez « Ouvrir les liens dans l'application de bureau » dans ses options, et il ouvre les liens Deezer dans l'application de bureau, ainsi que les liens Spotify, Apple Music ou YouTube Music sur Deezer. Deezer Link ne sera plus mis à jour.

Vous cliquez sur un lien Deezer et vous vous retrouvez dans le navigateur ? Deezer Link l'ouvre plutôt dans l'application de bureau, là où vous voulez écouter.

- Fonctionne avec tous les liens : titres, albums, playlists, artistes, podcasts, avec ou sans langue dans l'adresse (deezer.com/fr/…, deezer.com/pt-br/…).
- Rien à configurer : installez-la, puis ouvrez un lien.
- Sur Firefox, l'onglet resté ouvert se ferme tout seul.
- Aucun pistage : l'extension n'envoie aucune donnée à son développeur.

Nécessite l'application de bureau, donc non disponible sur ChromeOS.
